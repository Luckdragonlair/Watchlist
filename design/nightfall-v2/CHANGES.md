# Watchlist v2: changes from the latest review

This folder replaces earlier downloads completely. Watchlist Directions.dc.html (unchanged) is included because it holds the app icon and Binge v2 links to it.

## Binge v2
- Search box on every Android Binge view
- New Android view: Everything else scrolled to D, with a pinned section heading and an A–Z jump index on the right edge
- How the A–Z index works with touch, TalkBack and the keyboard: one adjustable control with a 44px touch area, tap or drag, each letter announced (for example "D, 5 shows"), swipe up or down to step letters, and search always available as the alternative
- "Not interested" renamed "Not for me" (filter, ⋯ menu and section rules)
- New section C: compact PC layout at 960px. Breakpoints: 1200px and up is full PC, 840–1199px is compact PC (one Backup menu, no posters), below 840px is the phone layout
- New rule: section headings stay pinned at the top while scrolling

## States v2
- Conflict (PC and Android): both versions are saved automatically as recovery copies (kept 30 days) before anything is replaced
- Restore (PC and Android): the current library is saved automatically as a recovery copy before it's replaced
- Recovery copies row added to the Android ⋯ menu
- "Export first" is now "Also export a backup file", an optional extra
- What next: the Pass button is now "Not for me", and the prompt is labelled "Proposed · deferred until the core app works"
- Status grid no longer squeezes at narrower widths

## Screens v2
- Android show detail, second screen: notes, catch-up, refresh and delete (this was missing from the earlier download)

## Flows v2
- Import: resumes where you left off, with queues ("Needs your choice", "Likely matches", "Done") and group approval of likely matches (marked as a proposal for the coding side)
- New section G, accessibility: 200% text phone, what a screen reader says during reordering, keyboard-only route, browser zoom, test checklist
- Title rule: a tooltip is never the only way to see a full title (tapping the title opens the detail page)
- "Not interested" and "Passed" replaced by "Not for me"
